# cc-forest-quota

管理林区资源、物种限额和采伐授权。

## 开发环境

- JDK 21
- Spring Boot 4.1.1
- Maven Wrapper 3.9.9
- H2

## 本地运行

启动服务：

    ./mvnw spring-boot:run

运行测试：

    ./mvnw clean test

## 业务规则

### 许可季与额度台账

- 许可季按「林区 + 许可季编号」唯一，包含起止日期和多个树种的核准材积；「林区 + 许可季 + 树种」组合唯一（数据库唯一约束）。
- 所有材积使用 `BigDecimal` 固定精度（小数 3 位），核准材积必须为正；占用量、实采量非负。
- 数据库检查约束保证 `占用量 + 实采量 <= 核准量`，任一树种的可用量 = 核准量 − 占用量 − 实采量。

### 采伐申请与批准

- 申请包含唯一申请号、作业日期区间和一个或多个树种的申请材积；作业日期必须完全落在许可季内。
- 批准时对所有树种一次性占用额度：任一树种可用量不足则整笔失败，不产生部分占用。
- 申请号幂等：相同申请号 + 相同内容重复提交返回原结果；内容不同返回 409 冲突。
- 并发安全：对额度行按树种排序加悲观写锁（`PESSIMISTIC_WRITE`），配合数据库检查约束，并发批准不会超卖任一树种额度；申请号唯一约束冲突时回读后按幂等规则处理。

### 实采申报与核销

- 许可证只能核销一次，申报必须覆盖许可证全部树种；各树种实采量不得为负、不得超过批准量。
- 核销时未使用的占用量立即释放回可用量，实采量永久计入许可季额度（不可再释放）。
- 重复申报相同内容返回原结果，不会重复释放；内容不同返回 409 冲突。

### 事务与审计

- 批准、核销、额度释放与审计事件（`APPROVED` / `SETTLED` / `RELEASED`）在同一事务内写入，要么全部成功要么全部回滚。

## API 概览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/seasons` | 创建许可季及树种核准额度 |
| GET | `/api/seasons/{forestArea}/{seasonCode}/ledger` | 许可季额度台账（核准/占用/实采/可用） |
| POST | `/api/permits/approvals` | 批准采伐申请（按申请号幂等） |
| POST | `/api/permits/{applicationNo}/settlement` | 提交实采申报并核销许可证 |
| GET | `/api/permits/{applicationNo}` | 许可证详情（批准/实采/释放量） |
| GET | `/api/permits/{applicationNo}/events` | 许可证审计事件 |
