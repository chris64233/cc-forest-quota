# cc-forest-quota

管理林区资源、物种限额和采伐授权。

## 主要业务规则

- **许可季与额度**：许可季包含林区、起止日期（结束日期必须晚于开始日期）以及多个树种的核准材积；同一许可季内树种唯一。材积统一使用 `BigDecimal` 固定 3 位小数，核准材积与申请材积必须为正数，实采材积不允许为负。
- **采伐申请**：申请包含唯一申请号、作业日期区间和一个或多个树种的申请材积（树种不可重复）。作业日期区间必须完全落在许可季内；每个树种的已批准未核销量（占用）与已实采量之和不得超过核准额度，即 `占用 + 实采 <= 核准`。
- **批准（占用额度）**：批准时一次性占用全部树种额度，任一树种额度不足（或未核准）则整笔驳回，不产生任何部分占用。申请号幂等：相同内容重复批准返回原许可证；内容不同返回 409 冲突。额度行按树种排序后加悲观锁（`SELECT ... FOR UPDATE`），并发批准不会超卖任一树种额度；申请号唯一约束兜底并发插入。
- **实采申报（核销）**：许可证完成后提交一次实采申报，必须且只能覆盖全部批准树种，各树种实采量不得为负且不得超过批准量。核销时未使用的占用量（批准量 - 实采量）立即释放回可用额度，实采量永久计入许可季已实采量。重复申报相同内容返回原结果、不会重复释放；内容不同返回 409 冲突。
- **暂停**：监管方可因天气、违规或林区封闭等原因暂停许可证，暂停事件记录生效时间与原因。暂停期间不能新增实采申报（返回 409），但已确认的历史实采与占用继续计入额度，暂停本身不触碰额度台账。仅 `APPROVED` 状态可暂停。
- **恢复**：仅 `SUSPENDED` 状态可恢复。恢复前重新检查许可季（许可季未结束）、许可证剩余期限（作业结束日期未过）和树种额度台账（台账存在且占用量与本证在占量一致），任一检查不通过则拒绝恢复并返回全部阻止原因；也可通过 `GET /api/licenses/{applicationNo}/resume-blockers` 单独查询阻止恢复的原因。
- **撤销**：撤销是终态，可从 `APPROVED` 或 `SUSPENDED` 状态进入。撤销时一次性释放尚未实采的全部占用量（按树种逐笔释放并写审计事件），已经实采的数量不得归还、永久计入许可季已实采量。已核销（`SETTLED`）的许可证不能撤销；撤销后不能再申报、暂停、恢复或再次撤销。
- **状态事件号与时间线**：暂停、恢复、撤销均需携带监管方分配的正整数事件号（`eventNo`）。事件号在同一许可证内幂等——相同事件号且内容一致的重试直接返回当前状态，不重复执行；事件号必须严格递增以保持时间顺序，相同事件号但内容不同、或事件号不大于已记录最大事件号时返回 409。每次状态变更写入 `license_status_event` 表（唯一约束 `(license_id, event_no)` 兜底），可通过时间线接口按事件号顺序查询。
- **并发一致性**：实采申报、暂停、恢复、撤销都先对许可证行加悲观写锁（`SELECT ... FOR UPDATE`），即所有变更都基于同一许可证版本串行处理：不会出现申报成功后其已消耗额度又被撤销释放，也不会重复释放未使用量；撤销与核销一样按树种排序后再锁额度行，避免死锁。
- **台账与审计**：许可季台账按树种展示核准、占用、实采与可用量；许可证详情展示各树种批准量、实采量与释放量，占用与释放明细接口展示各树种在占量。批准、核销、释放、暂停、恢复、撤销均在同一事务内写入审计事件，保证事务一致；数据库通过唯一约束与检查约束（`occupied + harvested <= authorized` 等）兜底。

## API 概览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/seasons` | 创建许可季 |
| POST | `/api/seasons/{seasonId}/quotas` | 为许可季核准某树种额度（重复树种返回 409） |
| GET | `/api/seasons/{seasonId}/ledger` | 许可季额度台账（核准/占用/实采/可用） |
| POST | `/api/licenses/approvals` | 批准采伐申请（幂等，占用额度） |
| POST | `/api/licenses/{applicationNo}/settlement` | 提交实采申报并核销（幂等，释放未用量） |
| POST | `/api/licenses/{applicationNo}/suspension` | 暂停许可证（事件号幂等，记录原因与生效时间） |
| POST | `/api/licenses/{applicationNo}/resumption` | 恢复许可证（恢复前重新检查许可季/期限/额度） |
| POST | `/api/licenses/{applicationNo}/revocation` | 撤销许可证（终态，一次性释放全部未实采占用） |
| GET | `/api/licenses/{applicationNo}` | 许可证详情（批准/实采/释放） |
| GET | `/api/licenses/{applicationNo}/timeline` | 许可证状态时间线（按事件号排序） |
| GET | `/api/licenses/{applicationNo}/quota-details` | 各树种占用与释放明细 |
| GET | `/api/licenses/{applicationNo}/resume-blockers` | 阻止恢复的原因查询（`resumable` + `reasons`） |
| GET | `/api/licenses/{applicationNo}/audit-events` | 许可证审计事件 |

状态变更请求体（暂停/恢复/撤销）：`{"eventNo": 1, "reason": "暴雨红色预警", "effectiveAt": "2026-09-27T08:00:00Z"}`，其中 `eventNo` 必填且必须为正整数并严格递增；暂停与撤销时 `reason` 必填；`effectiveAt` 缺省为当前时间。

错误语义：参数或业务校验失败 400，资源不存在 404，幂等冲突 409，额度不足 422。

## 开发环境

- JDK 21
- Spring Boot 4.1.1
- Maven Wrapper 3.9.9
- H2

    ./mvnw spring-boot:run

    ./mvnw clean test
