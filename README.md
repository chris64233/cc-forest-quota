# cc-forest-quota

管理林区资源、物种限额和采伐授权。

## 主要业务规则

- **许可季与额度**：许可季包含林区、起止日期（结束日期必须晚于开始日期）以及多个树种的核准材积；同一许可季内树种唯一。材积统一使用 `BigDecimal` 固定 3 位小数，核准材积与申请材积必须为正数，实采材积不允许为负。
- **采伐申请**：申请包含唯一申请号、作业日期区间和一个或多个树种的申请材积（树种不可重复）。作业日期区间必须完全落在许可季内；每个树种的已批准未核销量（占用）与已实采量之和不得超过核准额度，即 `占用 + 实采 <= 核准`。
- **批准（占用额度）**：批准时一次性占用全部树种额度，任一树种额度不足（或未核准）则整笔驳回，不产生任何部分占用。申请号幂等：相同内容重复批准返回原许可证；内容不同返回 409 冲突。额度行按树种排序后加悲观锁（`SELECT ... FOR UPDATE`），并发批准不会超卖任一树种额度；申请号唯一约束兜底并发插入。
- **实采申报（核销）**：许可证完成后提交一次实采申报，必须且只能覆盖全部批准树种，各树种实采量不得为负且不得超过批准量。核销时未使用的占用量（批准量 - 实采量）立即释放回可用额度，实采量永久计入许可季已实采量。重复申报相同内容返回原结果、不会重复释放；内容不同返回 409 冲突。已暂停或许可证已撤销时禁止申报（409）。
- **暂停**：监管方可因天气、违规或林区封闭等原因暂停许可证，暂停事件记录生效时间与原因（原因必填）。暂停期间不能新增实采申报，但已确认的历史实采继续计入许可季已实采量，额度台账不因暂停发生任何变动。仅 `APPROVED` 状态可暂停。
- **恢复**：仅 `SUSPENDED` 状态可恢复。恢复前重新检查：作业日期区间仍落在许可季内、许可证作业期限未届满、各树种额度台账正常（占用量仍覆盖该许可证未实采占用且未超限）。任一检查失败则恢复被阻止并返回全部原因；`GET /api/licenses/{applicationNo}/resume-check` 可随时查询阻止恢复的原因。
- **撤销**：`APPROVED` 或 `SUSPENDED` 状态可撤销，撤销是终态。撤销一次性释放尚未实采的全部占用量（按树种逐笔释放并写审计事件），已经实采的数量不得归还。`SETTLED`、`REVOKED` 状态不得再暂停、恢复或撤销。
- **状态事件**：每次暂停/恢复/撤销都携带监管方分配的事件号并记录生效时间。事件号在许可证维度幂等：相同事件号相同内容重放返回当前状态、不产生任何重复效果（不会重复释放未使用量）；相同事件号内容不同返回 409 冲突。新事件的生效时间不得早于上一事件的生效时间，保证状态时间线严格按时间顺序推进。实采申报、暂停、恢复、撤销均对许可证行加悲观锁（`SELECT ... FOR UPDATE`），并发操作在同一许可证版本上串行化：申报成功后撤销不会再释放其已消耗额度，并发撤销也不会重复释放。
- **台账与审计**：许可季台账按树种展示核准、占用、实采与可用量；许可证详情展示各树种批准量、实采量与释放量；`GET /api/licenses/{applicationNo}/timeline` 展示许可证状态时间线（事件号、类型、原因、生效时间）。批准、核销、释放、暂停、恢复、撤销均在同一事务内写入审计事件，保证事务一致；数据库通过唯一约束与检查约束（`occupied + harvested <= authorized`、事件号唯一等）兜底。

## API 概览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/seasons` | 创建许可季 |
| POST | `/api/seasons/{seasonId}/quotas` | 为许可季核准某树种额度（重复树种返回 409） |
| GET | `/api/seasons/{seasonId}/ledger` | 许可季额度台账（核准/占用/实采/可用） |
| POST | `/api/licenses/approvals` | 批准采伐申请（幂等，占用额度） |
| POST | `/api/licenses/{applicationNo}/settlement` | 提交实采申报并核销（幂等，释放未用量） |
| POST | `/api/licenses/{applicationNo}/suspension` | 暂停许可证（事件号幂等，需原因与生效时间） |
| POST | `/api/licenses/{applicationNo}/resumption` | 恢复许可证（恢复前重新检查，被阻止返回 400 及原因） |
| POST | `/api/licenses/{applicationNo}/revocation` | 撤销许可证（终态，一次性释放全部未实采占用） |
| GET | `/api/licenses/{applicationNo}` | 许可证详情（批准/实采/释放） |
| GET | `/api/licenses/{applicationNo}/timeline` | 许可证状态时间线（按生效时间排序） |
| GET | `/api/licenses/{applicationNo}/resume-check` | 查询是否可恢复及阻止恢复的原因 |
| GET | `/api/licenses/{applicationNo}/audit-events` | 许可证审计事件 |

错误语义：参数或业务校验失败 400，资源不存在 404，幂等冲突 409，额度不足 422。

## 开发环境

- JDK 21
- Spring Boot 4.1.1
- Maven Wrapper 3.9.9
- H2
